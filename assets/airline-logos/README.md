# Airline logos (optional)

The interview picker shows a branded colored monogram card for each
airline by default. If you have the **right to use** an airline's official
logo, drop a PNG here and it will be used automatically instead:

- `vietjet.png` — Vietjet Air
- `vna.png` — Vietnam Airlines
- `sunphuquoc.png` — Sun PhuQuoc Airways

Guidelines:
- Transparent-background PNG, roughly 320×112 px (displayed max 56px tall).
- These are **trademarks** of their owners. Only add a logo if you are
  authorized to use it (e.g. official partner/recruitment-training
  material). The app does not bundle any airline logos for this reason.
- Filename must match the airline id exactly; if a file is missing the
  colored monogram fallback is shown — nothing breaks.
